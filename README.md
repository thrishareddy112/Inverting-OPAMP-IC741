Aim:
To design and simulate an inverting amplifier using IC 741.

Components Required:

IC 741 Op-Amp
2 Resistors
Dual DC power supply (+12V and −12V)
Function generator/Input source
Oscilloscope

Working:
The input signal is applied to the inverting (-) terminal through the input resistor. The non-inverting (+) terminal is connected to ground. A feedback resistor is connected from the output to the inverting terminal.

Formula:

$$ A_v = \frac{V_o}{V_i} = -\frac{R_f}{R_{in}} $$

The negative sign indicates that the output is 180° out of phase with the input.

Result:
The IC 741 successfully amplifies the input signal and produces an inverted output.
